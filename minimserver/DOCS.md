# MinimServer

## ライセンスへの同意が必要です

- このアドオンを使用するには、MinimServer 2 のライセンス条項への同意が必要です。条項は https://minimserver.com/license-popup.html で確認できます。
- このアドオンは MinimServer のバイナリを同梱していません。アドオンイメージをお使いの Home Assistant 上でビルドする際に、公式サイトからダウンロードします。
- 設定で `accept_eula` を有効にすると、上記の条項を読み、同意したものとみなされます。有効にするまでアドオンは起動しません。
